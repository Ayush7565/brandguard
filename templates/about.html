About BrandGuard and how AI is used

What it does

BrandGuard reviews content before it is published. It compares the text with the organisation's approved guidelines, facts, terminology, claims and palette, explains every issue, shows the source it relied on, and suggests a fix that only replaces the flagged words. Creators accept, edit or dispute each suggestion. Managers and reviewers make the final decision.

Disclosure of AI and external services

  • Rule-based checks (always on, no AI): terminology, promotional claims, approved facts, palette, accessibility and basic tone rules.
  • AI layer (optional): the Claude API by Anthropic, model {{ model }}, looks for tone, messaging, fact and claim issues using only the approved passages it is given. {% if ai_enabled %}It is enabled in this deployment.{% else %}It is not enabled in this deployment, so only rule-based checks run.{% endif %}
  • What is sent: the submitted text, the creator's stated goal, the channel and the relevant approved passages. Email addresses and phone numbers are replaced with placeholders before sending. Nothing is sent when the AI layer is off.
  • No findings without proof: an AI finding must quote an approved source. The quote is checked in code. If it cannot be verified, the finding is labelled "Needs human judgment" and given low confidence.
  • Human control: nothing is applied or approved automatically.
  • Cost and abuse protection: AI use is rate limited per user and per day.

Known limitations (prototype)

  • Text review only in this version. Image and document review, an insights dashboard and guideline-gap detection are planned for Round 3.
  • Demo data is a fictional brand, and the demo database may reset when the server restarts. Do not enter real confidential material.
  • Rule-based fact checking looks for numbers near trigger keywords, so unusual phrasing can be missed. Reviewers should still read the content.
  • AI findings can be wrong. That is why they always need a person to accept them.
